Entrar no Mamômetro

Rastreamento automático de demos das partidas do grupo. Cola as informações da tua conta Steam abaixo.

  1. Identifica tua conta Steam — abre steamcommunity.com em outra aba, clica no teu nome de usuário (canto superior direito) e copia a URL do perfil que aparece na barra de endereço. Vai ser tipo https://steamcommunity.com/id/teu_nick/ ou https://steamcommunity.com/profiles/17digitos/.
  2. Abra o wizard oficial do CS2 em outra aba, faça login na Steam se pedir, e gere o Match History Access Code. É o token persistente do CS2 (formato AAAA-1111-BBBB) — não confunde com o "Login Auth Code" de 5 minutos do Steam client.
    Se o link não carregar o formulário, vê as instruções detalhadas aqui (wiki oficial).
  3. Jogue uma partida de CS2 e copie o share code do final do match: menu principal → Watch → Your Matches → última partida → Copy Share Code (formato CSGO-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX).
  4. Cole tudo aqui embaixo. Você só precisa fazer isso uma vez — o bot cuida dos próximos share codes automaticamente. Se o teu Match History Access Code expirar um dia, volta aqui e re-onboarda.
A URL completa do teu perfil Steam, ou teu SteamID64 (17 dígitos). O bot usa pra te identificar no roster.
Gerado pelo wizard do CS2. É persistente (não expira em 5 min). Se já tens um gerado, ele aparece na mesma página — pode usar o que já tens.
CS2 → menu principal → Watch → Your Matches → última partida jogada → Copy Share Code. Tem que ser uma partida com o Valve Matchmaking (Premier, Competitive, etc — não funciona com FACEIT).
